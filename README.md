# Customer Churn Analysis

## Problem
Customer churn is a major issue for businesses. This project analyzes customer data to identify factors that lead to churn.

## Tools Used
Python, Pandas, Matplotlib

## Steps
- Data Cleaning
- Exploratory Data Analysis
- Feature Analysis

## Key Insights
- Customers with higher charges are more likely to churn
- Contract type impacts retention
- Long-term customers are less likely to leave

## Result
Helps businesses take actions to reduce churn and improve retention
